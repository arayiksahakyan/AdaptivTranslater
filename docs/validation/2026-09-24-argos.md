# Argos integration validation — 2026-09-24

Host: Linux, Python 3.12.8, Qt/PySide6 6.11.2, offscreen Qt. Target: Windows 10/11
x64 Python 3.12. All Windows/native Argos checks remain unexecuted.

## Dependency research

Inspected official PyPI metadata and the Argos `v1.11.0` source (`translate.py`,
`settings.py`, `sbd.py`, `package.py`, `utils.py`), MiniSBD 0.9.5 wheel source, and
the official Argos model index. Source/model metadata downloads were read-only
investigation, separate from application runtime.

Argos 1.11.0 depends on CTranslate2 >=4,<5, SentencePiece >=0.2,<0.3, Stanza 1.10.1,
spaCy, MiniSBD, packaging, and sacremoses >=0.0.53,<0.2. MiniSBD requires ONNX Runtime,
NumPy, and filelock; Stanza brings PyTorch. Shared Paddle dependencies were checked
as a combined graph, not by downgrading installed packages.

Initial command:

```bash
.venv/bin/python -m pip install --dry-run --report /tmp/argos-linux-resolve.json argostranslate==1.11.0 -r requirements-ocr.txt -r requirements.txt
```

Cancelled with Ctrl+C while pip was downloading runtime wheels. No installation
occurred. Replaced this with a temporary uv metadata resolver under `/tmp`:

```bash
.venv/bin/python -m pip install --target /tmp/argos-resolver uv
/tmp/argos-resolver/bin/uv pip compile requirements.txt requirements-ocr.txt requirements-translation.txt --python-version 3.12 --python-platform x86_64-pc-windows-msvc --only-binary :all: --cache-dir /tmp/argos-uv-cache -o /tmp/argos-windows-resolution.txt
/tmp/argos-resolver/bin/uv pip compile requirements.txt requirements-ocr.txt requirements-translation.txt --python-version 3.12 --python-platform x86_64-unknown-linux-gnu --only-binary :all: --cache-dir /tmp/argos-uv-cache -o /tmp/argos-linux-resolution.txt
```

Both succeeded. Windows resolved 109 packages. Important resolved versions:

| Package | Version |
| --- | --- |
| argostranslate | 1.11.0 |
| minisbd | 0.9.5 |
| paddleocr / paddlepaddle | 3.3.2 / 3.2.2 |
| ctranslate2 / sentencepiece | 4.8.2 / 0.2.2 |
| stanza / torch | 1.10.1 / 2.14.0 |
| spacy / onnxruntime | 3.8.16 / 1.30.0 |
| numpy / protobuf / pydantic | 2.5.3 / 7.36.2 / 2.13.5 |

No metadata conflict found. These are a resolution snapshot, not a runtime lock or
proof of Windows native compatibility. Existing venv dependencies were not changed.
The Argos runtime was not installed and real-model inference was not executed in this task.

HTTP HEAD checks only (no model body downloads):

```bash
curl -I -L --max-time 30 https://argos-net.com/v1/translate-en_ru-1_9.argosmodel
curl -I -L --max-time 30 https://github.com/LibreTranslate/MiniSBD/releases/download/v0.0.1/en.onnx
```

Both returned HTTP 200 at their final URLs. Content-Length: 195746693 and 188043
bytes respectively. The official index identifies the directional translation
package as version 1.9, compatible with Argos 1.11.0.

142 tests pass on Linux. Argos tests inject doubles; no automated test downloads
models or sends real translation requests. Coverage includes installed path/direct
and pivot guards, auxiliary-file deletion, configuration forcing local operation,
sanitized errors/recovery, model reuse, cache isolation, UI selection/privacy,
explicit installation, optional smoke behavior, and worker responsiveness.
Configuration assertions also check ONNX Runtime telemetry opt-out/API disable
and suppression of Argos's INFO-level payload logger. These do not replace native
Windows network monitoring.
All 109 pre-existing tests, including Google mocked-network tests, remain intact.

instruction to install `requirements-translation.txt` or select Mock. This verifies
missing-dependency handling only, not real inference. Final lint/compilation and
offscreen startup results are recorded in PROGRESS.md.
